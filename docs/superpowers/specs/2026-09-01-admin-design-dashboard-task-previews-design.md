# 高级美工仪表盘与运营美工全量任务展示调整设计

## 背景

高级美工仪表盘中的“美工完成效率排行”已不再需要。运营美工全量任务当前只能通过详情查看参考图和作品图，表格缺少快速预览，同时搜索框不支持按款号查找。

## 目标

- 从高级美工仪表盘移除“美工完成效率排行”。
- 在运营美工全量任务表格增加“参考图”和“作品预览”两列。
- 让运营美工全量任务支持按款号搜索。
- 保持现有详情、筛选、分页、导出、删除、权限和任务流转逻辑不变。

## 界面行为

### 高级美工仪表盘

- 顶部统计卡中，将现有 `doing_count` 卡片的显示名称由“作图中”改为“待审核”，只改名称，不修改数值字段或统计口径。
- 移除顶部“已驳回”统计卡；后端 `rejected_count` 数据保持不变，其他页面和统计仍可继续使用。
- 完整移除“美工完成效率排行”卡片。
- 同步移除该图表对应的前端 DOM 引用、ECharts 实例初始化、缩放和销毁代码。
- 不修改仪表盘统计接口，也不影响其他排行榜和统计表。

### 运营美工全量任务

- 仅在现有表格新增“参考图”和“作品预览”两列，不重排或删除其他列。
- 每列显示对应分类的第一张图片，缩略图尺寸为 `48 x 48`。
- 点击缩略图后，使用现有图片查看器浏览该分类的全部图片。
- 缩略图支持直接拖出，并沿用现有文件拖拽逻辑保留原文件名。
- 对应分类没有图片时显示 `-`；不在这两列展示非图片附件。
- 该展示只增加到运营美工全量任务页面，其他全量任务分区维持现状。

## 数据加载

运营美工全量任务列表目前不包含文件数组。后端在完成当前页任务分页查询后，复用现有批量文件查询，一次性读取本页所有任务的文件并挂载到各行。

该方案每页只增加一次文件查询，不逐行请求任务详情，也不修改数据库结构或文件存储方式。

## 款号搜索

- 运营美工全量任务搜索框提示改为“搜索编号/标题/款号”。
- 当 `taskGroup` 为 `design` 时，全量任务查询的关键词条件增加 `style_number`。
- 运营助理和客服基础美工全量任务继续只按原有字段搜索，避免扩大未要求的行为范围。
- 分页、排序、发布人、美工、状态和日期筛选保持不变。

## 验证

- 高级美工仪表盘顶部显示“待审核”而不再显示“作图中”，且不再显示“已驳回”统计卡。
- 高级美工仪表盘不再渲染“美工完成效率排行”，其他统计模块仍正常显示。
- 运营美工全量任务显示新增的两列；首图缩略图可点击查看同类全部图片，也可直接拖出。
- 无图任务在对应列显示 `-`。
- 使用完整或部分款号可以查到对应运营美工任务，其他全量任务分区搜索规则不变。
- 现有详情、导出、下载、删除、筛选、分页和任务流转测试不回归。

## 非目标

- 不修改任务详情页布局或功能。
- 不新增文件上传、下载或预览接口。
- 不修改权限、任务状态、任务流转和数据库表结构。
- 不调整其他全量任务分区的表格列。
- 不执行应用打包或远程推送。
