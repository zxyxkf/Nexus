# 美工项目类型完成统计与人员负载调整设计

## 目标

在不改变任务流转、审核规则和数据库结构的前提下，完成三项调整：

1. 高级美工仪表盘的“项目类型完成统计”支持查看全部、当月和上月数据。
2. 美工设计师个人统计新增当年 1-12 月的项目类型完成统计。
3. 发布任务时的指定人员负载排除已经提交、正在等待审核的任务。

## 统计口径

“项目类型完成统计”采用审核通过口径：

- 只统计状态为 `finished` 的任务。
- 全部数据统计所有已审核通过任务，不限制完成日期。
- 当月和上月按任务的 `finish_time` 归属月份。
- 个人统计的 1-12 月数据按当前年份的 `finish_time` 归属月份。
- `doing` 表示作品已经提交、等待审核，不计入项目类型完成统计。
- 没有有效 `finish_time` 的历史任务可以计入“全部”，但不归入当月、上月或年度月份列，避免用其他时间猜测审核通过时间。
- 项目类型沿用任务的积分项目 `score_item_id` 与系统配置中的项目名称，不增加新的项目类型配置。

## 后端数据设计

继续使用现有统计接口，不增加新接口，也不让前端拉取分页任务后自行聚合。

在统计服务中增加一个复用的项目类型完成聚合逻辑。每个项目类型返回：

```js
{
  project_name: '主图',
  count: 18,
  current_month_count: 4,
  last_month_count: 3,
  monthly_counts: [
    { month: 1, count: 0 },
    { month: 2, count: 1 },
    // 始终补齐到 12 月
    { month: 12, count: 0 }
  ]
}
```

- `GET /api/task/stats/admin/detail` 中的 `designerStats[].project_stats` 使用上述结构。
- `GET /api/task/stats/my` 仅在美工设计师身份下增加同结构的 `project_stats`。
- 当月和上月直接由同一份返回数据切换，避免每次点击重新请求接口。
- 上月统计使用完整日期范围计算，因此一月份查看“上月”时能够正确统计上一年十二月。
- 不修改现有积分、月度积分、日统计和导出接口的口径。

## 高级美工仪表盘

“项目类型完成统计”卡片标题栏调整为局部控制：

- 左侧保留标题“项目类型完成统计”。
- 右侧增加 `全部 / 当月 / 上月` 分段选择。
- 默认选中“全部”。
- 分段选择只控制当前卡片下方的项目类型统计表，不影响仪表盘中的卡片、积分排行、日统计或发布人统计。
- 切换时不重新加载页面，表格按 `count`、`current_month_count` 或 `last_month_count` 即时展示。
- 表格原有行列结构保持不变：行是美工，列是工作项目类型，无数据展示 `0`。

## 美工个人统计

在“月度积分统计”下方增加“月度项目类型完成统计（当前年份）”：

- 行表头为“工作项目类型”。
- 每一行对应一个已配置的美工工作项目类型。
- 列表头依次为 `1月` 至 `12月`。
- 单元格展示该项目类型在对应月份审核通过的任务数量，无数据展示 `0`。
- 只在美工设计师角色的个人统计页展示，不影响基础美工和运营助理的个人统计页。
- 复用现有 `StatsPanel`，通过显式属性开启该表格，默认关闭，避免共享组件影响其他角色。

## 指定人员负载

发布任务页继续使用现有人员选择组件和人员列表接口，只调整后端 `active_tasks` 的状态条件：

- `accepted`：已接单、尚未提交，计入负载。
- `rejected`：审核驳回、需要返工，计入负载。
- `doing`：已提交、等待审核，不计入负载。
- `finished` 和 `wait` 继续不计入指定人员负载。

此规则应用于复用该人员查询的美工、基础美工和运营助理列表。前端仍展示现有的任务数量和悬浮任务明细，不改变选择、发布和自动接单逻辑。

## 边界与兼容性

- 不增加或修改数据库表、字段和迁移。
- 不修改任务状态值或任何状态流转。
- 不修改审核、驳回、重新提交、积分计算或任务权限。
- 不改变高级仪表盘其他统计模块。
- 不改变发布任务表单和人员选择组件的交互结构。
- 不执行构建、打包或远程推送。

## 验证要求

后端验证应覆盖：

- 只有 `finished` 任务进入项目类型完成统计。
- 当月、上月和全年 1-12 月按 `finish_time` 正确归类，包括跨年上月。
- 个人统计仅为美工设计师返回项目类型月度数据。
- 人员负载包含 `accepted`、`rejected`，排除 `doing`、`finished`。

前端验证应覆盖：

- 高级美工仪表盘的分段选择位于“项目类型完成统计”标题栏内。
- 默认展示全部数据，切换当月或上月只改变该表格。
- 美工个人统计展示项目类型行和 1-12 月列。
- 基础美工与运营助理个人统计不出现新增表格。
- 原有发布任务人员选择和任务发布功能保持可用。
