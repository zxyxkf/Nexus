# 素材库与客服款式图联动设计

日期：2026-09-02  
状态：待实现

## 1. 目标与范围

新增一个独立的“素材库”分区，并将客服发布基础美工任务与素材库款式图联动。素材库用于按商品库、款式、图片三层管理图片；客服可以从素材库选择款式和图片，发布任务时把选中的图片复制为任务自己的款式图。

本次只影响：

- 素材库新页面及其后端接口；
- 客服发布任务页面；
- 客服“我的任务”、客服作品审核、客服任务详情；
- 基础美工任务详情中的指定颜色展示。

本次不改变任何既有任务状态、审核、接单、上传、重开、打款或通知逻辑，不改变运营、运营助理、美工设计师等其他角色的相关页面。

## 2. 已确认的业务规则

- 素材库内容全公司共享，不按店铺隔离。
- 商品库名称全局唯一。
- 款式名称只需在所属商品库内唯一；不同商品库允许同名。
- 素材库权限为单一权限 `material.library`。授权后拥有查看、创建、重命名、上传、删除、排序和颜色修正全部权限；未授权人员不显示侧边栏入口。
- 侧边栏新增独立“素材库”分区，位置在“打款跟踪”之后、“数据”之前。
- 商品库、款式卡片和图片都支持删除；删除上级时级联删除下级内容，并二次确认。
- 素材库图片使用独立存储目录，路径由超级管理员在系统配置中单独配置。
- 上传沿用现有图片格式和单文件大小限制，每个款式不限制图片数量。
- 图片保留原始文件名，同时支持重命名；重命名后重新进行颜色自动识别，也允许人工修正颜色。
- 每张图片只归属一个颜色。无法识别颜色的图片不参与颜色筛选；未选择颜色时仍展示全部图片。
- 图片顺序由素材库保存的排序值决定；支持拖拽排序，发布预览和任务详情均按该顺序展示。
- 发布任务时选择款式和图片均为可选；选择款式但不勾选图片也允许发布。
- 发布任务后，选中的素材图片复制为任务独立副本。素材库图片后续删除、重命名或排序，不影响已发布任务。

## 3. 素材库页面

素材库由三个独立页面组成，每次点击卡片进入新页面，不在同一页面同时展开：

### 3.1 商品库首页

- 顶部显示标题、全局搜索框和“新建商品库”。
- 下方以卡片网格展示商品库，卡片显示名称、款式数量和少量预览缩略图。
- 卡片支持进入、重命名和删除。

### 3.2 款式卡片页

- 面包屑可返回素材库首页或商品库首页。
- 页面只显示当前商品库下的款式卡片。
- 支持新建款式、进入、重命名和删除。
- 款式卡片显示款式名称、图片数量和预览缩略图。

### 3.3 图片管理页

- 顶部显示商品库名 / 款式名和返回导航。
- 页面顶部先显示上传框，支持点击选择文件和拖拽上传。
- 图片上传成功后实时显示在上传框下方。
- 图片数量过多时，继续向下滚动才显示后续内容；不一次性把全部图片挤在首屏。
- 图片支持预览、下载、拖出、重命名、删除、拖拽排序和颜色修正。

### 3.4 搜索

首页搜索框同时支持商品库名称和款式名称。

- 搜索商品库时，结果显示商品库卡片并可直接进入。
- 搜索款式时，结果显示“商品库 / 款式名”，点击直接进入对应款式的图片管理页。
- 同名款式通过商品库前缀区分。

## 4. 客服发布任务联动

客服发布页面改为两栏布局：左侧保留原发布任务表单，右侧新增款式素材预览。原有字段、校验、指定人员、参考图上传和发布流程保持不变。

### 4.1 款号与颜色

- “款号”改为可搜索下拉框，选项来自所有商品库下的款式，显示“商品库 / 款式名”。
- 款号仍为可选项，可以不选素材库款式直接发布。
- 选择款式后，“指定颜色”变为颜色筛选下拉框。
- 颜色先依据图片文件名自动识别，也可在素材库中人工修正。
- 只有存在有颜色标记的图片时才显示颜色选项；没有可识别颜色时保持无选项。
- 未选择颜色时，右侧显示当前款式全部图片；选择颜色后，只显示对应颜色图片。

### 4.2 图片选择

- 右侧图片按素材库排序值展示，缩略图一行优先展示 5 张，图片过多时继续滚动查看。
- 图片默认全部不选，点击图片可多选。
- 切换颜色不会清空已选图片；筛选只改变当前可见图片，新勾选图片追加到已有选择，重复图片不能重复加入。
- 左侧任务描述下方保留原“参考图”上传框，旁边新增“款式图”区域。
- “款式图”区域实时同步右侧已选素材图片。
- 选择款式但不勾选任何图片时仍允许发布，不生成款式图文件。

### 4.3 发布保存

发布请求增加可选的素材参数：

- `materialStyleId`：所选款式 ID，可为空；
- `materialImageIds`：选中的图片 ID 数组，可为空。

后端验证图片属于所选款式后，把选中的素材图片复制到任务独立目录，并以 `task_file.file_category = 'style'` 写入任务文件记录。参考图继续使用原有 `reference` 分类。

## 5. 任务列表与详情展示

### 5.1 客服“我的任务”

将原“指定颜色”列改为“款式图”。单元格显示第一张款式图缩略图和图片数量；点击可打开全部款式图预览。

### 5.2 客服作品审核

在“款号”旁新增“款式图”展示，显示第一张缩略图和图片数量，点击可查看全部图片。

### 5.3 客服和基础美工任务详情

将原“指定颜色”字段替换为“款式图”区域，展示任务发布时复制的全部款式图，并沿用现有图片预览、下载和拖出能力。参考图仍单独展示，不与款式图混合。

## 6. 数据与接口设计

新增独立数据表：

- `material_product`：商品库名称、创建人、时间等；名称全局唯一。
- `material_style`：商品库 ID、款式名称、创建人、时间等；商品库内名称唯一。
- `material_image`：款式 ID、原始文件名、显示文件名、颜色、颜色来源、排序值、存储相对路径、大小、类型、创建人和时间等。

新增接口统一挂在 `/api/material-library`：

- 商品库查询、创建、重命名、删除；
- 款式按商品库查询、创建、重命名、删除；
- 图片上传、查询、重命名、颜色修正、删除、排序；
- 商品库 / 款式联合搜索。

所有接口要求 `material.library` 权限。名称唯一性由数据库约束和服务层校验双重保证。

## 7. 文件存储与失败处理

- 素材库目录与任务上传目录完全分离，使用系统配置中的独立路径。
- 图片数据库只保存相对路径，服务端解析路径时拒绝目录穿越和前端伪造路径。
- 发布任务时先校验素材图片和源文件，再执行复制；失败时清理临时文件，不留下半成品。
- 数据库写入失败时删除本次复制的文件；文件复制失败时不创建任务记录。
- 商品库、款式和图片删除均执行数据库记录和物理文件清理；级联删除前必须二次确认。
- 重命名冲突、排序版本过期、源文件缺失、格式或大小超限均返回明确错误，不影响其他记录。

## 8. 迁移与兼容

SQLite 和 MySQL 创建同等结构的素材表、索引和素材库路径配置项。迁移脚本必须幂等，服务器启动时自动创建缺失表和配置，不修改现有任务记录，不要求导入旧任务数据。

`task_info.specified_color` 字段暂不删除，避免影响既有接口和筛选；新页面不再将其作为主要展示内容。当前生产环境没有需要兼容的旧任务款式图数据。

## 9. 验收标准

- 只有授予 `material.library` 的人员能看到并操作素材库。
- 三层页面均为独立卡片页面，返回和搜索路径正确。
- 上传框支持点击选择和拖拽，图片实时出现在上传框下方。
- 图片重命名、颜色自动识别 / 人工修正、删除和拖拽排序可持久化。
- 客服可搜索选择款式、按颜色筛选、跨筛选追加选择图片，并正常发布任务。
- 发布后的款式图是任务独立副本，素材库删除或改名不影响任务。
- 客服和基础美工页面按要求展示款式图；其他角色页面保持原样。
- 级联删除、权限拒绝、重复名称、上传失败和复制失败均有明确反馈且不产生脏数据。
- 现有任务发布、接单、上传、审核、打款和通知回归验证通过。
